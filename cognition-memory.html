Cognition & Memory Enhancers

These techniques can help you understand, remember and connect information more effectively.

Dual Coding

What is it? Dual coding combines words with visuals, such as diagrams, images or mind maps, to represent information.

How is it helpful? Using both words and visuals can help you understand and remember information by representing ideas in different ways.

How to use it: Create diagrams, labelled drawings, mind maps or timelines alongside your written notes.

Elaborative Interrogation

What is it? Elaborative interrogation involves asking yourself questions about why a fact or idea is true.

How is it helpful? It encourages you to connect new information to what you already know and understand the reasons behind it.

How to use it: When learning a fact, ask yourself questions such as "Why does this happen?" or "Why is this important?"

Mnemonic Devices

What is it? Mnemonic devices are memory aids that help you remember information using things such as acronyms, phrases or associations.

How is it helpful? They can make difficult or lengthy information easier to remember and recall.

How to use it: Create an acronym, rhyme, phrase or other memorable association for the information you need to remember.

Concrete Examples

What is it? Concrete examples involve connecting an abstract idea to a specific, real-world example.

How is it helpful? Examples can make difficult concepts easier to understand by showing how they work in a practical situation.

How to use it: After learning a concept, find or create a real-world example that demonstrates how the concept works.
